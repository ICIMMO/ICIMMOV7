# 03 – Launch-Checkliste

## Technik

- [ ] Alle Unterseiten erreichbar
- [ ] Navigation auf Desktop und Mobilgerät geprüft
- [ ] Formulare getestet
- [ ] 404/Redirects geprüft
- [ ] Bilder optimiert
- [ ] `sitemap.xml` mit finaler Domain aktualisiert
- [ ] `robots.txt` mit finaler Domain aktualisiert

## Rechtliches

- [ ] Impressum final
- [ ] Datenschutzerklärung final
- [ ] Cookie-/Tracking-Thema geprüft
- [ ] Barrierefreiheitstext geprüft

## SEO

- [ ] Jede Seite hat einen eindeutigen Title
- [ ] Jede Seite hat eine Meta Description
- [ ] H1 nur einmal pro Seite
- [ ] Interne Links geprüft
- [ ] Open Graph Bilder/Texte ergänzt

## Pflege

- [ ] Gemeinsame CSS-Datei angelegt
- [ ] Gemeinsame JS-Datei angelegt
- [ ] Wiederverwendbare Komponenten geplant
- [ ] Später ggf. Astro oder Eleventy prüfen
